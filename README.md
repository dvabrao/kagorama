# 🚽 Kagorama — by nob

O fliperama do banheiro: Cata-Cocô, Pingue-Pongue, Quebra-Tijolos, Invasores, Patrulha do Rio e Rali de Resistência.

- **Baixar o APK:** vá em **Releases** (à direita) e toque em `Kagorama.apk`.
- **Jogar no computador:** abra `web/index.html` (ou o link da versão web).

O APK é gerado automaticamente pelo GitHub Actions a cada atualização (`.github/workflows/gerar-apk.yml`).

- `web/` — o jogo (HTML, sons em `sfx/`, fonte em `fonts/`)
- `android/` — app Android que abre o jogo em tela cheia
